- Implemented request validation, quota checks, and persistent container state.
- Integrated Go services with PostgreSQL and Incus for container provisioning.
- Worked on asynchronous operations, error handling, and state transitions.
- Configured database migrations and automated deployment workflows.
- Set up Linux service management and release-based deployments using systemd.

**Engineering focus:** Backend architecture, container orchestration, infrastructure automation, and reliable deployment workflows.
